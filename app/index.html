Prova real

Este site é entregue por uma pipeline

Cada push na main constrói a imagem, publica no Docker Hub e faz rollout no Oracle Kubernetes Engine com uma ServiceAccount restrita ao namespace — sem cluster-admin.

  • Nginx não-root, filesystem somente leitura, seccomp
  • RollingUpdate com maxUnavailable: 0
  • TLS automático (cert-manager) e DNS (external-dns)
  1. Git pushGitHub • main
  2. Build & pushDocker Buildx • Docker Hub
  3. Deploykubectl • RBAC mínimo
  4. OKEIngress • TLS • HPA
